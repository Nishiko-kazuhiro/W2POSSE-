# Week03 ミニドリル 1問目 - Margin・Padding練習

## 問題

Week02で学習したmargin・paddingの概念を使って、ボックスモデルを理解し、要素間の余白を適切に調整してください。

### 目標

ページ下部の練習問題セクションにある「このボックスを調整してください」のボックスに対して、以下のスタイルを適用してください：

1. **上下のmargin**: `20px`
2. **左右のpadding**: `30px`
3. **背景色**: 薄い青色（`#e3f2fd`）

### 学習内容

このドリルでは以下の重要な概念を学習できます：

- **ボックスモデル**の理解
- **Margin（外側の余白）**と**Padding（内側の余白）**の違い
- 要素間の余白調整の実践

### ボックスモデルとは

CSSのボックスモデルは以下の4つの領域で構成されています：

1. **Content（コンテンツ）**: 実際の内容が表示される部分
2. **Padding（内側の余白）**: コンテンツと境界線の間の余白
3. **Border（境界線）**: 要素の境界線
4. **Margin（外側の余白）**: 要素と他の要素の間の余白

### Margin vs Padding

- **Padding**: 要素の内側の余白。背景色や背景画像が適用される
- **Margin**: 要素の外側の余白。背景色は適用されない（透明）

### 修正箇所

`css/style.css` の最下部にあるコメントアウトされたCSSコードを参考にしてください。

### 修正方法

1. `css/style.css` を開く
2. ファイルの最下部にあるコメント（`/* */`）を外す
3. または、`.practice-box` クラスに以下のプロパティを追加する：
   ```css
   .practice-box {
     margin: 20px 10px;
     padding: 10px 30px;
     background-color: #e3f2fd;
   }
   ```

### 終了条件

- 練習ボックスの上下に20pxのmarginが設定されている
- 練習ボックスの左右に30pxのpaddingが設定されている
- 練習ボックスの背景色が薄い青色（#e3f2fd）になっている

### 学習ポイント

この問題では以下のCSS重要概念を練習できます：

- **margin**: 要素の外側の余白を指定
- **padding**: 要素の内側の余白を指定
- **ボックスモデル**: CSSレイアウトの基礎となる概念

これらはWebレイアウトを作成する上で最も重要な基礎概念です。marginとpaddingの違いを理解することで、より精密なレイアウト調整が可能になります。

### 応用のヒント

- `margin: 20px 10px;` は上下20px、左右10pxを意味します
- `padding: 10px 30px;` は上下10px、左右30pxを意味します
- 値を4つ指定すると「上 右 下 左」の順番で適用されます
