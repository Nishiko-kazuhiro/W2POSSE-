# Week8-2: JavaScript概要 - 四則演算練習

## 学習目標
- JavaScriptでの四則演算の書き方を習得する
- 演算子の優先順位を理解する
- 括弧を使った計算順序の制御を学ぶ
- 余り演算子（%）の使い方を覚える

## 問題

### 準備
1. `index.html` をブラウザで開く
2. F12キーを押すか、右クリック→「検証」で開発者ツールを開く
3. 「Console」タブを選択する

### 基本練習
`js/script.js` ファイルの最後に以下の練習問題の答えを追加してください。

#### 練習1: 基本的な四則演算
以下の計算結果をconsole.logで出力してください：
```javascript
// 1. 45 + 23
// 2. 78 - 34
// 3. 12 * 9
// 4. 84 / 7
```

#### 練習2: 余り演算
以下の余りを求めてください：
```javascript
// 1. 25 % 4 （25を4で割った余り）
// 2. 17 % 3 （17を3で割った余り）
// 3. 100 % 7 （100を7で割った余り）
```

#### 練習3: 演算子の優先順位
以下の計算結果を予想してから、console.logで確認してください：
```javascript
// 1. 5 + 3 * 2
// 2. (5 + 3) * 2
// 3. 20 - 10 / 2
// 4. (20 - 10) / 2
```

#### 練習4: 複雑な計算
以下の計算を行ってください：
```javascript
// 1. (8 + 4) * (15 - 9)
// 2. 50 / 5 + 20 * 3
// 3. (100 + 50) / (6 - 1)
```

#### 練習5: 実用的な計算
以下の実用的な計算を行ってください：
```javascript
// 1. 商品価格800円に消費税10%を加えた税込価格
// 2. 時給1200円で6時間働いた場合の給料
// 3. 1個150円のりんごを8個買った場合の合計金額
// 4. 12000円を3人で等分した場合の1人あたりの金額
```

#### 練習6: 小数点の計算
以下の小数点を含む計算を行ってください：
```javascript
// 1. 3.14 + 2.86
// 2. 10.5 - 4.3
// 3. 2.5 * 6
// 4. 15.6 / 4
```

### 終了条件

- [ ] 余り演算子（%）を理解している

- [ ] 括弧を使って計算順序を制御できる

- [ ] 練習問題1〜6をすべて完了している

## 重要なポイント
- **演算子の優先順位**: 掛け算・割り算は足し算・引き算より先に計算される
- **括弧の使用**: 括弧内の計算が最優先で実行される
- **余り演算子（%）**: 割り算の余りを求める（例: 10 % 3 = 1）
- **小数点**: JavaScriptは自動的に小数点の計算を処理する
