# Week02 ミニドリル 1問目 - CSS基礎練習

## 問題

Week02で学習したCSS基礎プロパティ（`color`, `font-size`, `text-align`）を使って、指定されたテキストをスタイリングしてください。

### 目標

ページ下部の「このテキストをスタイリングしてください」というテキストに対して、以下のスタイルを適用してください：

1. **文字サイズ**: `20px`
2. **文字色**: 青色（`#3498db`）
3. **テキスト配置**: 中央揃え

### 修正箇所

`css/style.css` の最下部にあるコメントアウトされたCSSコードを参考にしてください。

### 修正方法

1. `css/style.css` を開く
2. ファイルの最下部にあるコメント（`/* */`）を外す
3. または、`.target-text` クラスに以下のプロパティを追加する：
   ```css
   .target-text {
     font-size: 20px;
     color: #3498db;
     text-align: center;
   }
   ```

### 終了条件

- 「このテキストをスタイリングしてください」のテキストが20pxのサイズになっている
- テキストの色が青色（#3498db）になっている  
- テキストが中央揃えで表示されている

### 学習ポイント

この問題では以下のCSS基礎プロパティを練習できます：

- **font-size**: 文字の大きさを指定
- **color**: 文字の色を指定
- **text-align**: テキストの水平方向の配置を指定

これらはWeb開発で最も基本的で重要なCSSプロパティです。
