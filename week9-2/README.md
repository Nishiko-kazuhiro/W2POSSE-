# Week9-2: JavaScript基礎文法 - 条件分岐練習

## 学習目標
- if文の基本的な使い方を習得する
- else if文を使った複数条件の処理を理解する
- 比較演算子（===、!==、>、<、>=、<=）を使える
- 論理演算子（&&、||）を理解する
- 実用的な条件分岐を書けるようになる

## 問題

### 準備
1. `index.html` をブラウザで開く
2. F12キーを押すか、右クリック→「検証」で開発者ツールを開く
3. 「Console」タブを選択する

### 基本練習
`js/script.js` ファイルの最後に以下の練習問題の答えを追加してください。

#### 練習1: 基本的なif文
以下の条件分岐を作成してください：
```javascript
// 1. 変数 temperature = 30 として、25度以上なら「暑いです」と出力
// 2. 変数 money = 500 として、1000円以上なら「お金持ちです」と出力
// 3. 変数 isRaining = true として、雨なら「傘を持って行きましょう」と出力
```

#### 練習2: if-else文
以下の条件分岐を作成してください：
```javascript
// 1. 変数 score = 65 として、60点以上なら「合格」、未満なら「不合格」
// 2. 変数 age = 16 として、18歳以上なら「成人」、未満なら「未成年」
// 3. 変数 number = 7 として、偶数なら「偶数」、奇数なら「奇数」（ヒント: % 2 === 0）
```

#### 練習3: if-else if-else文
以下の条件分岐を作成してください：
```javascript
// BMI値による判定（BMI = 22とする）
// 18.5未満: 「やせ型」
// 18.5以上25未満: 「普通体重」
// 25以上30未満: 「肥満（1度）」
// 30以上: 「肥満（2度以上）」
```

#### 練習4: 比較演算子の練習
以下の変数を使って比較結果をconsole.logで出力してください：
```javascript
let x = 15;
let y = 20;
// 1. x === y の結果
// 2. x !== y の結果
// 3. x > y の結果
// 4. x < y の結果
// 5. x >= 15 の結果
// 6. y <= 20 の結果
```

#### 練習5: 論理演算子（&&）の練習
以下の条件をすべて満たす場合に「条件を満たしています」と出力してください：
```javascript
let userAge = 25;
let hasLicense = true;
let hasExperience = true;
// 年齢が20歳以上 かつ 免許を持っている かつ 経験がある
```

#### 練習6: 論理演算子（||）の練習
以下のいずれかの条件を満たす場合に「割引対象です」と出力してください：
```javascript
let customerAge = 70;
let isStudent = false;
let isMember = true;
// 65歳以上 または 学生 または 会員
```

#### 練習7: 成績判定システム
以下の条件で成績を判定してください：
```javascript
let testScore = 88;
// 90点以上: 「A」
// 80点以上90点未満: 「B」
// 70点以上80点未満: 「C」
// 60点以上70点未満: 「D」
// 60点未満: 「F」
```

#### 練習8: 料金計算システム
以下の条件で映画料金を計算してください：
```javascript
let age = 14;
let isStudent = true;
let basePrice = 1800;
// 12歳未満: 1000円
// 60歳以上: 1200円
// 学生: 1500円
// その他: 1800円
// 最終料金をconsole.logで出力
```

#### 練習9: 時間帯による挨拶
以下の条件で挨拶を変更してください：
```javascript
let currentHour = 16;
// 5時〜11時: 「おはようございます」
// 12時〜17時: 「こんにちは」
// 18時〜21時: 「こんばんは」
// その他: 「お疲れ様です」
```

#### 練習10: パスワード強度チェック
以下の条件でパスワードの強度を判定してください：
```javascript
let password = "MyPassword123";
let length = password.length;
// 8文字未満: 「弱い」
// 8文字以上12文字未満: 「普通」
// 12文字以上: 「強い」
```

## 重要なポイント
- **厳密等価演算子（===）**: 型も含めて完全に等しいかチェック
- **論理演算子**: &&（かつ）、||（または）
- **条件の順序**: より具体的な条件を先に書く
- **括弧の使用**: 複雑な条件では括弧で優先順位を明確にする

## よくある間違い
- = と === の混同（= は代入、=== は比較）
- 条件の順序が間違っている
- 論理演算子の使い方を間違える
