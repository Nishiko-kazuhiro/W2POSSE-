# PH1ミニドリル

PH1ではHTML・CSS・JavaScriptを利用し、Webサイト制作を行っていきます。

このミニドリルは、各週のカリキュラムで学習した内容を実践的に練習するための演習問題集です。段階的な学習により、基礎から応用まで着実にスキルを身につけることができます。

## 📚 学習フロー

### Phase 1: HTML・CSS基礎（Week01-04）
**HTML基礎からレイアウト応用まで**

- **Week01**: HTML基礎タグの習得
- **Week02**: CSS基礎とFlexboxレイアウト
- **Week03**: レイアウト応用（margin・padding、中央寄せ）
- **Week04**: Grid Layoutによる高度なレイアウト

### Phase 2: JavaScript基礎（Week08-09）
**プログラミング基礎の習得**

- **Week08**: JavaScript概要（console.log、四則演算）
- **Week09**: JavaScript基礎文法（変数・定数、条件分岐）

### Phase 3: JavaScript応用（Week10-16）
**動的なWebサイト制作**

- **Week10-16**: DOM操作、イベント処理、ライブラリ活用など

## 🚀 開始前の準備

### 必要なツール
- **テキストエディタ**: Visual Studio Code（推奨）
- **Webブラウザ**: Google Chrome（推奨）
- **Live Server拡張機能**: VSCodeでローカルサーバーを簡単に起動

### Live Server の導入
HTMLファイルをブラウザで開くと内容が表示されますが、直接ファイルを開くとパス指定などで問題が起きる可能性があります。

そのため、サイト表示確認を行う際には**必ずローカルサーバーを立ち上げて確認**してください。

以下の記事を参考に、エディタ（VSCode）にLive Serverという拡張機能を導入しましょう。
簡単にローカルサーバーを立ち上げることができます！

[VSCode Live Server の使い方](https://www.freecodecamp.org/japanese/news/vscode-live-server-auto-refresh-browser/)

## 🔧 トラブルシューティング

### よくある問題と解決方法

**Q: 画像が表示されない**
- A: ファイルパスが正しいか確認してください。相対パスの使い方を見直しましょう。

**Q: CSSが適用されない**
- A: HTMLファイルでCSSファイルが正しくリンクされているか確認してください。

**Q: JavaScriptが動作しない**
- A: ブラウザの検証ツール（F12）でコンソールエラーを確認してください。

**Q: Live Serverが起動しない**
- A: VSCodeでHTMLファイルを開いた状態で右クリック→「Open with Live Server」を選択してください。

## 💡 学習のコツ

1. **毎日少しずつでも継続する** - 短時間でも毎日コードに触れることが重要
2. **手を動かして学ぶ** - 理論だけでなく実際にコードを書いて理解を深める
3. **エラーを恐れない** - エラーは学習の機会。原因を調べて解決する経験が成長につながる
4. **他の人のコードを読む** - 良いコードの書き方を学ぶ最良の方法
5. **アウトプットする** - 学んだことを人に説明したり、ブログに書いたりして定着させる

## ⚠️ 重要な注意事項

### ドリルの正しい取り組み方

1. **自分で考えて実装する** - ドリルは練習問題です。答えを見る前に必ず自分で考えて実装してください

4. **エラーを恐れない** - エラーが出ても諦めず、原因を調べて解決する経験が重要です
5. **復習を大切にする** - 定期的に過去のドリルを見直し、理解を深めてください

### 学習効果を最大化するために

- **手を動かす**: コードを実際に書いて動作確認する
- **理解してから進む**: なぜそのコードが動くのかを理解する
