# Week01 ミニドリル 1問目 - HTML基礎タグの練習

## 問題

基本的なHTMLタグ（h1, h2, p, a, img）を使って、自己紹介ページを完成させてください。

現在のHTMLファイルには基本的な構造が用意されていますが、以下の要素が不足しています：

1. **見出しタグ（h1, h2）** - ページタイトルとセクションタイトル
2. **段落タグ（p）** - 自己紹介文
3. **リンクタグ（a）** - 外部サイトへのリンク
4. **画像タグ（img）** - プロフィール画像の表示

## 学習目標

- HTMLの基本的なタグの使い方を理解する
- 見出し（h1, h2）の階層構造を理解する
- 段落（p）タグで文章を構造化する
- リンク（a）タグのhref属性の使い方を学ぶ
- 画像（img）タグのsrc属性とalt属性の使い方を学ぶ

## 修正箇所

以下のタグを適切に使用してください：

- `<h1>` - メインタイトル用
- `<h2>` - セクションタイトル用  
- `<p>` - 段落用
- `<a href="URL">` - リンク用
- `<img src="画像パス" alt="説明文">` - 画像用

## 終了条件

- [ ] h1タグでページのメインタイトルが表示されている
- [ ] h2タグでセクションタイトルが表示されている
- [ ] pタグで自己紹介文が段落として表示されている
- [ ] aタグで外部サイトへのリンクが設置されている
- [ ] imgタグでプロフィール画像が表示されている（画像ファイルがない場合は代替テキストが表示される）
- [ ] ブラウザで開いた時に、構造化された自己紹介ページとして表示される

## ヒント

- HTMLタグは開始タグ `<タグ名>` と終了タグ `</タグ名>` で囲んで使用します
- aタグのhref属性にはリンク先のURLを指定します
- imgタグのalt属性には画像の説明文を入れます（アクセシビリティのため重要です）
- 見出しタグ（h1, h2）は文字の大きさではなく、情報の階層を表すために使用します
