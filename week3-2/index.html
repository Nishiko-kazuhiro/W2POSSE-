中央寄せ練習

このページではtext-alignとmargin: 0 autoを使った中央寄せを学習します。

中央寄せの種類

text-align: center

インライン要素やテキストを中央寄せ

インライン要素

親要素にtext-align: centerを指定

margin: 0 auto

ブロック要素

ブロック要素自体にmargin: 0 autoを指定
