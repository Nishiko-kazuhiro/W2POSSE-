# Week03 ミニドリル 2問目 - 中央寄せ練習

## 問題

Week02で学習した中央寄せの手法（`text-align: center`、`margin: 0 auto`）を使って、様々な要素を適切に中央寄せしてください。

### 目標

ページ下部の練習問題セクションにある3つの問題を解決してください：

1. **問題1**: テキストを中央寄せ（`text-align: center`を使用）
2. **問題2**: ボックスを中央寄せ（`margin: 0 auto`を使用）
3. **問題3**: ボックスとテキスト両方を中央寄せ（両方の手法を組み合わせ）

### 学習内容

このドリルでは以下の重要な概念を学習できます：

- **text-align: center**（インライン要素・テキストの中央寄せ）
- **margin: 0 auto**（ブロック要素の中央寄せ）
- 両方の手法を組み合わせた実践的なレイアウト

### 中央寄せの種類と使い分け

#### 1. text-align: center
- **対象**: インライン要素、インラインブロック要素、テキスト
- **使用方法**: 親要素に`text-align: center`を指定
- **適用例**: テキスト、画像、インライン要素

```css
.parent {
  text-align: center;
}
```

#### 2. margin: 0 auto
- **対象**: ブロック要素（幅が指定されている必要がある）
- **使用方法**: 中央寄せしたい要素自体に`margin: 0 auto`を指定
- **適用例**: div、section、固定幅のコンテナ

```css
.block-element {
  width: 300px; /* 幅の指定が必要 */
  margin: 0 auto;
}
```

### 重要なポイント

1. **text-align: center**は親要素に指定する
2. **margin: 0 auto**は中央寄せしたい要素自体に指定する
3. **margin: 0 auto**を使う場合は、要素に幅（width）の指定が必要
4. 両方を組み合わせることで、ボックスもテキストも中央寄せできる

### 修正箇所

`css/style.css` の最下部にあるコメントアウトされたCSSコードを参考にしてください。

### 修正方法

1. `css/style.css` を開く
2. ファイルの最下部にあるコメント（`/* */`）を外す
3. または、以下のCSSを追加する：

**問題1の解答:**
```css
.practice-text-area {
  text-align: center;
}
```

**問題2の解答:**
```css
.practice-box {
  margin: 0 auto;
}
```

**問題3の解答:**
```css
.practice-combined-box {
  margin: 0 auto;
}

.practice-combined-text {
  text-align: center;
}
```

### 終了条件

- **問題1**: テキストが中央寄せされている
- **問題2**: ボックスが中央寄せされている
- **問題3**: ボックスが中央寄せされ、かつボックス内のテキストも中央寄せされている

### 学習ポイント

この問題では以下のCSS重要概念を練習できます：

- **text-align**: テキストやインライン要素の水平配置を指定
- **margin**: 要素の外側の余白を指定（0 autoで中央寄せ）
- **レイアウトの組み合わせ**: 複数の手法を組み合わせた実践的なレイアウト

これらはWebレイアウトで最も頻繁に使用される中央寄せの手法です。適切な使い分けができるようになることで、様々なレイアウト要求に対応できるようになります。

### 応用のヒント

- `text-align: center`は継承されるプロパティです
- `margin: 0 auto`は上下0px、左右autoを意味します
- 両方を組み合わせることで、より複雑なレイアウトも実現できます
- モダンなレイアウトではFlexboxやCSS Gridも使用されますが、基本的な中央寄せ手法として重要です
