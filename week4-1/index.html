Grid Layoutの仕組み

上のレイアウトは以下のCSSで作成されています：

.grid-container {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 20px;
}

ポイント：

  • display: gridでGrid Layoutを有効化
  • grid-template-columns: 1fr 1frで2列の等幅レイアウト
  • 1frは利用可能な空間を等分する単位
  • gapでグリッドアイテム間の間隔を設定
