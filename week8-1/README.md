# Week8-1: JavaScript概要 - console.log練習

## 学習目標
- JavaScriptの基本的な概念を理解する
- console.logの使い方を習得する
- ブラウザの開発者ツールの使い方を覚える

## 問題

### 準備
1. `index.html` をブラウザで開く
2. F12キーを押すか、右クリック→「検証」で開発者ツールを開く
3. 「Console」タブを選択する

### 基本練習
`js/script.js` ファイルの最後に以下のコードを追加して、コンソールで結果を確認してください。

#### 練習1: 自己紹介
あなたの名前を出力するコードを書いてください。
```javascript
// 例: console.log("私の名前は○○です");
```

#### 練習2: 好きな数字
あなたの好きな数字を出力してください。
```javascript
// 例: console.log("私の好きな数字は", 7, "です");
```

#### 練習3: 簡単な計算
以下の計算結果をconsole.logで出力してください：
- 20 + 15
- 50 - 12
- 8 × 6
- 100 ÷ 4

#### 練習4: メッセージの種類
以下の3種類のメッセージを出力してください：
- console.log() で通常のメッセージ
- console.warn() で警告メッセージ
- console.error() でエラーメッセージ

### 終了条件
- [ ] ブラウザのコンソールを開くことができる
- [ ] console.logで文字列を出力できる
- [ ] console.logで数値を出力できる
- [ ] console.logで計算結果を出力できる
- [ ] console.warn()とconsole.error()の違いを理解している
- [ ] 練習問題1〜4をすべて完了している

## 参考
- JavaScriptはWebページに動的な機能を追加するプログラミング言語です
- console.logはデバッグ（問題の発見・解決）によく使われます
- 開発者ツールはWeb開発において必須のツールです
