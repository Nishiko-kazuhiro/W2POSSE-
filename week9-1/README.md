## 重要なポイント
- **let**: 値を変更できる変数を宣言する
- **const**: 値を変更できない定数を宣言する
- **変数名**: 意味のある名前を付ける（例: userName, totalPrice）
- **命名規則**: キャメルケース（例: firstName）や定数は大文字（例: MAX_VALUE）
- **データ型**: 文字列（string）、数値（number）、真偽値（boolean）など

## よくある間違い
- constで宣言した値を変更しようとする
- 変数を宣言せずに使用する
- 意味のない変数名を使う（例: a, b, c）
