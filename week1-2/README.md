# Week01 ミニドリル 2問目 - HTML属性の練習

## 問題

HTML属性（id, class, href, src）の使い方を理解し、適切に属性を設定してください。

現在のHTMLファイルには様々な要素が配置されていますが、以下の属性が正しく設定されていない、または不足している箇所があります：

1. **id属性** - 要素に一意の識別子を付ける
2. **class属性** - 要素にスタイル用のクラス名を付ける
3. **href属性** - リンクの遷移先を指定する
4. **src属性** - 画像ファイルのパスを指定する

## 学習目標

- id属性とclass属性の違いを理解する
- href属性を使ったリンクの設定方法を学ぶ
- src属性を使った画像の表示方法を学ぶ
- 属性を使ったCSSセレクターとの連携を理解する

## 修正箇所

以下の属性を適切に設定してください：

### id属性の設定
- ヘッダー要素に `id="main-header"`
- 各セクションに `id="about"`, `id="skills"`, `id="contact"`
- フッター要素に `id="main-footer"`

### class属性の設定
- サイトタイトルに `class="site-title"`
- セクションタイトルに `class="section-title"`
- プロフィール画像に `class="profile-image"`
- 各リンクに適切なクラス名

### href属性の設定
- ナビゲーションリンクにページ内リンク（#about, #skills, #contact）
- 外部サイトへのリンク（GitHub, Twitter等）
- メールリンク（mailto:）

### src属性の設定
- プロフィール画像のパスを正しく設定

## 終了条件

- [ ] id属性が適切に設定されている（ページ内で一意）
- [ ] class属性が適切に設定されている（CSSでスタイリング可能）
- [ ] href属性でページ内リンクが正しく動作する
- [ ] href属性で外部リンクが正しく動作する
- [ ] src属性で画像が正しく表示される（画像ファイルがない場合は代替テキストが表示される）
- [ ] ブラウザで開いた時に、ナビゲーションリンクをクリックすると該当セクションにスクロールする

## ヒント

- **id属性**：ページ内で一意である必要があります。CSSでは`#id名`、JavaScriptでは`getElementById()`で選択できます
- **class属性**：複数の要素に同じクラス名を付けることができます。CSSでは`.class名`で選択できます
- **href属性**：
  - ページ内リンク：`href="#id名"`
  - 外部リンク：`href="https://example.com"`
  - メールリンク：`href="mailto:email@example.com"`
- **src属性**：画像ファイルへの相対パスまたは絶対パスを指定します
- **alt属性**：画像が表示されない場合の代替テキストとして重要です

## 属性の基本構文

```html
<!-- id属性（一意の識別子） -->
<div id="unique-id">内容</div>

<!-- class属性（スタイル用クラス） -->
<p class="text-style">段落</p>

<!-- href属性（リンク先） -->
<a href="https://example.com">外部リンク</a>
<a href="#section1">ページ内リンク</a>

<!-- src属性（画像パス） -->
<img src="./images/photo.jpg" alt="写真の説明">
